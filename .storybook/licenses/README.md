# Demo icon licenses

These notices cover icons copied into the Storybook and website demos. None of
them ship in the npm package.

The Storybook-only Radio Card guide symbols adapt glyph geometry distributed
through React Icons 5.6.0; its MIT notice is in
[`REACT-ICONS-MIT.txt`](REACT-ICONS-MIT.txt). The Lucide glyphs carry the
copyright and ISC permission notice in [`LUCIDE-ISC.txt`](LUCIDE-ISC.txt).
Some Lucide shapes derive from Feather; its MIT notice is in
[`FEATHER-MIT.txt`](FEATHER-MIT.txt).
The Remix Icon glyphs use Apache-2.0; its full text is in
[`REMIX-APACHE-2.0.txt`](REMIX-APACHE-2.0.txt). The adaptations place copied SVG
geometry in Solid JSX and TypeScript path data, with a Lever UI-owned wrapper.
The Storybook-only Slider custom thumb copies the `MdGraphicEq` glyph from
[Google's Material Design Icons](https://github.com/google/material-design-icons)
through React Icons 5.6.0. Material Design Icons are licensed under
Apache-2.0; its full text is in
[`MATERIAL-DESIGN-APACHE-2.0.txt`](MATERIAL-DESIGN-APACHE-2.0.txt).
The Storybook-only Icon examples also use a Material Design `3d_rotation`
glyph, a Heroicons heart, and a Lucide-inspired package outline. Their
respective notices are in the Material Design, Heroicons, and Lucide license
files above.
The Storybook-only Empty State examples use a Heroicons color swatch and a
Lucide-inspired shopping cart, covered by the same notices.
The Storybook-only Download Trigger examples use Lucide download and
image-down glyphs, covered by the Lucide notice above.
The Storybook-only Switch guide copies `FaMoon` and `FaSun` geometry from
[Font Awesome Free](https://github.com/FortAwesome/Font-Awesome) through
React Icons 5.6.0 and converts it to Solid path data. The original icons are
credited to Fonticons, Inc. Font Awesome's SVG icons are licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); the original
[free icon license and attribution](https://fontawesome.com/license/free)
apply. The guide also copies `HiCheck` and `HiX` geometry from
[Heroicons](https://github.com/tailwindlabs/heroicons) through React Icons
5.6.0. Heroicons is licensed under MIT; its copyright and permission notice
are in [`HEROICONS-MIT.txt`](HEROICONS-MIT.txt).
The Storybook-only Toggle guide copies `LuBold`, `LuVolume2`, `LuVolumeX`,
`LuX`, and `LuInfo` geometry from Lucide through React Icons 5.6.0. The
information-tip example copies `HiOutlineInformationCircle` geometry from
Heroicons through the same package. Their notices are the React Icons,
Lucide, Feather, and Heroicons license files linked above.
The Storybook-only Timeline examples also reproduce Lucide ship, check,
package, pen, and x glyph geometry from the React Icons reference.
The Storybook-only Native Select InputGroup example reproduces the Lucide user
glyph from the same reference.
The Storybook-only List indicator example reproduces Lucide circle-check and
circle-dashed paths; the Spinner custom indicator reproduces the Lucide loader.
The Tag variant table reproduces Heroicons check and outline briefcase paths.
The Storybook-only Menu examples reproduce Lucide action glyphs and Heroicons
settings and sort glyphs. Their notices are linked above.
The Storybook-only Pagination examples reproduce Heroicons chevrons.
The Heroicons notice is linked above.
The Storybook-only Rating custom icon reproduces the Ionicons heart through
React Icons 5.6.0, and the Marquee examples draw the Ionicons `logo-figma`
glyph, which Bootstrap Icons does not include. Ionicons is MIT-licensed by
Ionic; its notice is in
[`IONICONS-MIT.txt`](IONICONS-MIT.txt) and the
[official license](https://github.com/ionic-team/ionicons/blob/main/LICENSE).
These source examples and local license copies are excluded from the
published Lever UI package.
